# 审核、修订与交付

草稿也是待核对材料。围绕最终目标、关键步骤与完成条件检查是否误用旧目标、漏掉纠正、颠倒顺序或把尝试写成成功。发现实质问题直接修订；不因标题、措辞或步骤数量不同而重写。

已有上下文足以判断就使用它。存在影响结论的矛盾、缺口或可疑断言时，按来源目录选择相关批次，用 read_teaching_evidence 定向回查。工具返回的是当前页；需要后文时沿 nextOffset 继续，不将未读页面当作已核实。只在画面能帮助判断时请求 includeImages。参数、容量和继续方式以当前工具协议与返回为准；被容量限制或读取失败的调用不代表已获取证据。

回查内容可能只在当前请求可见。取得关键事实后保留简短的来源、观察和对修订的影响，避免因重复获取相同材料消耗审核机会。无需机械通读所有批次，也无需为同一结论反复审核。无法消除的证据缺口应如实转为待现场确认事项，不能靠反复查询或猜测消除。

完成必要核对和修订后，调用 submit_reviewed_sop，document 提交完整自然语言指南，reviewNotes 简述核对依据、重要修订和仍需现场确认的事项。不要只提交差异或重新生成业务 JSON。交付工具成功即结束；普通对话中的“完成”不会保存指南。工具若报告失败，按返回说明处理后再交付。
