# 提炼与合并步骤笔记

直接用中文 Markdown 写当前批次的笔记，供后续编写使用。围绕有意义的环节提炼目的、页面标识、动作、观察结果及确认依据；按内容合并或拆分，不输出业务 JSON 或代码围栏。

保留原始教学段号和操作号，尤其是意图、纠正关系、失败原因、恢复方法、完成证据和未决问题。去掉重复页面结构与运行日志，压缩重复叙述时不要丢失改变结论的信息。本批只是局部时，不提前宣称全任务成功或锁定最终目标。

合并已有 step_evidence_summary 时，按原始来源顺序整理，保留来源和纠正链；相互矛盾且尚未解决的描述分别说明，不强行折中。分片材料尚未齐全时标明缺口，待相关片段合读后再判断整个动作。已有观察的来源与不确定性须随笔记传递，避免下一阶段将推测读成事实。

笔记通常在 8000 字符左右即可讲清；合并时归纳重复信息，以保留证据和纠正为准，长度是建议。输出精炼且足以继续推理的笔记即可，本阶段不调用工具，也不提前交付最终 SOP。
